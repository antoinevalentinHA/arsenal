# ARSENAL — Contrats · Imprimerie

Ce dossier regroupe les contrats relatifs au domaine **imprimerie** : capteurs de
bruit des machines industrielles, et surveillance d'ambiance des zones de stockage.

Chaque contrat de bruit transforme le signal brut d'une source de bruit en grandeur
exploitable. Le contrat de surveillance d'ambiance des stocks définit la mesure,
la surveillance et l'alerte de dépassement des conditions de stockage déclarées
(Home Assistant hors système qualité).
